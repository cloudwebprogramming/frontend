# [역할 4] 할일 등록 및 분배 컴포넌트 연동 명세 (팀원 공유용)

이 문서는 **역할 4 (할 일 등록 및 분배)** 프론트엔드 UI 컴포넌트와의 연동을 위해 제공되는 최소한의 명세입니다.

---

## 1. TaskFormModal 컴포넌트 스펙

- **컴포넌트 경로**: `src/deployment/components/task/TaskFormModal.jsx`
- **목적**: 특정 프로젝트 내에 새로운 할 일을 등록하기 위한 입력 폼을 **모달(Modal) 오버레이** 형태로 제공합니다. 

### 1.1. Props 명세

상위 컴포넌트(예: 프로젝트 상세 화면, 사이드바, 상단 탭 버튼 등)에서 `TaskFormModal`을 임포트하여 렌더링할 때 아래의 Props를 사용하여 열고 닫기를 제어합니다.

```jsx
import { useState } from 'react';
import TaskFormModal from './deployment/components/task/TaskFormModal';

function App() {
  const [isModalOpen, setIsModalOpen] = useState(false);

  return (
    <div>
      {/* 1. 모달을 띄울 트리거 버튼 */}
      <button onClick={() => setIsModalOpen(true)}>할 일 추가</button>

      {/* 2. 모달 컴포넌트 주입 */}
      <TaskFormModal 
        isOpen={isModalOpen} 
        onClose={() => setIsModalOpen(false)}
        projectId={3} 
        onTaskCreated={(newTask) => console.log('등록된 할 일:', newTask)} 
      />
    </div>
  );
}
```

| Prop명 | 타입 | 필수 여부 | 설명 | 비고 |
| :--- | :--- | :--- | :--- | :--- |
| `isOpen` | Boolean | **필수** | 모달의 노출 상태 제어 | true: 노출, false: 숨김 |
| `onClose` | Function | **필수** | 모달 내부의 닫기/취소 클릭 시 상위 상태 변경용 콜백 | |
| `projectId` | Number | **필수** | 할 일을 등록할 대상 프로젝트 ID | 누락 시 기본값 1 |
| `onTaskCreated` | Function | 선택 | 등록 완료 시 호출될 콜백 함수 | 인자로 생성된 Task 객체 전달 |

## 2. 스타일 격리 (CSS Isolation)

- **스타일 시트**: `src/deployment/components/task/TaskFormModal.css`
- **간섭 방지**: 모든 CSS 스타일은 `.tf-modal-container`, `.tf-modal-overlay`, `.tf-input`, `.tf-button`과 같이 `tf-` (TaskForm) 프리픽스가 적용된 클래스명으로 캡슐화되어 있습니다. 기존 전역 스타일과 간섭을 일으키지 않습니다.

## 3. [2라운드 추가] 모달 내 데이터 연동 의존성 및 반응형 보정

### 3.1. 확장된 Props 명세

```jsx
<TaskFormModal 
  isOpen={isModalOpen} 
  onClose={() => setIsModalOpen(false)}
  initialProjectId={1} // (선택) 진입 시 드롭다운 기본 프로젝트 ID 지정
  onTaskCreated={(newTask) => console.log('할 일 등록 완료:', newTask)} 
/>
```

| Prop명 | 타입 | 필수 여부 | 설명 | 비고 |
| :--- | :--- | :--- | :--- | :--- |
| `initialProjectId` | Number | 선택 | 모달 진입 시 드롭다운에서 최초 선택될 프로젝트 ID | 기본값은 첫 번째 프로젝트 |

### 3.2. 모달 내 데이터 연동 의존성
본 모달은 기동 시 내부적으로 아래 API들을 호출해 프로젝트 및 팀원 드롭박스를 동적으로 완성합니다.

1. **프로젝트 선택 드롭박스**:
   - API: `GET /api/v1/projects`
   - 매핑 요건: `id` (value), `title` (label)
2. **담당자 지정 드롭박스**:
   - API: `GET /api/v1/projects/{projectId}/members`
   - 매핑 요건: `username` (value & label)

### 3.3. 스타일 반응형 스크롤 지원
- 모달 카드에 `max-height: 85vh; overflow-y: auto;`가 선언되어 있어 화면 줌 확대/축소 시 자동으로 스크롤바가 생성됩니다.
- 모바일 가로/세로 폭 대응 미디어 쿼리가 적용되어 모달 깨짐을 원천 차단했습니다.
